# Installation Resources

Installation allows the adversary to maintain persistence inside the environment.

## Persistence Tools

*   **[SharPersist](https://github.com/fireeye/SharPersist)** <span class="badge badge-opensource">Open Source</span>: Windows persistence toolkit written in C#.
*   **[SharpStay](https://github.com/0xthirteen/SharpStay)** <span class="badge badge-opensource">Open Source</span>: .NET project for installing Persistence.
*   **[SharpHide](https://github.com/outflanknl/SharpHide)** <span class="badge badge-opensource">Open Source</span>: Tool to create hidden registry keys.
*   **[ScheduleRunner](https://github.com/netero1010/ScheduleRunner)** <span class="badge badge-opensource">Open Source</span>: C# tool to customize scheduled task for persistence.
*   **[SharpEventPersist](https://github.com/improsec/SharpEventPersist)** <span class="badge badge-opensource">Open Source</span>: Persistence by writing/reading shellcode from Event Log.
*   **[IIS-Raid](https://github.com/0x09AL/IIS-Raid)** <span class="badge badge-opensource">Open Source</span>: A native backdoor module for Microsoft IIS.
*   **[SharPyShell](https://github.com/antonioCoco/SharPyShell)** <span class="badge badge-opensource">Open Source</span>: Tiny and obfuscated ASP.NET webshell for C# web applications.
*   **[Kraken](https://github.com/kraken-ng/Kraken)** <span class="badge badge-opensource">Open Source</span>: Modular multi-language webshell.
*   **[HiddenDesktop](https://github.com/WKL-Sec/HiddenDesktop)** <span class="badge badge-opensource">Open Source</span>: HVNC for Cobalt Strike.
*   **[DAMP](https://github.com/HarmJ0y/DAMP)** <span class="badge badge-opensource">Open Source</span>: The Discretionary ACL Modification Project: Persistence Through Host-based Security Descriptor Modification.
*   **[reGeorg](https://github.com/sensepost/reGeorg)** <span class="badge badge-opensource">Open Source</span>: The successor to reDuh, pwn a bastion webserver and create SOCKS proxies.
*   **[ABPTTS](https://github.com/nccgroup/ABPTTS)** <span class="badge badge-opensource">Open Source</span>: TCP tunneling over HTTP for web application servers.
*   **[pivotnacci](https://github.com/blackarrowsec/pivotnacci)** <span class="badge badge-opensource">Open Source</span>: A tool to make socks connections through HTTP agents.
