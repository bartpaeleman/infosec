# Command and Control (C2) Resources

Command and Control (C2) channels allow the attacker to issue instructions to the compromised devices.

## Remote Access Tools (RAT) & C2 Frameworks

*   **[Cobalt Strike](https://cobaltstrike.com/)** <span class="badge badge-commercial">Commercial</span>: Software for Adversary Simulations and Red Team Operations.
*   **[Villain](https://github.com/t3l3machus/Villain)** <span class="badge badge-opensource">Open Source</span>: High level stage 0/1 C2 framework that can handle multiple reverse TCP & HoaxShell-based shells.
*   **[Kubesploit](https://github.com/cyberark/kubesploit)** <span class="badge badge-opensource">Open Source</span>: Cross-platform post-exploitation HTTP/2 Command & Control server and agent focused on containerized environments.
*   **[Sliver](https://github.com/BishopFox/sliver)** <span class="badge badge-opensource">Open Source</span>: General purpose cross-platform implant framework.
*   **[Havoc](https://github.com/HavocFramework/Havoc)** <span class="badge badge-opensource">Open Source</span>: Modern and malleable post-exploitation command and control framework.
*   **[Empire](https://github.com/BC-SECURITY/Empire)** <span class="badge badge-opensource">Open Source</span>: Post-exploitation framework that includes a pure-PowerShell Windows agent.
*   **[PoshC2](https://github.com/nettitude/PoshC2)** <span class="badge badge-opensource">Open Source</span>: Proxy aware C2 framework.
*   **[Covenant](https://github.com/cobbr/Covenant)** <span class="badge badge-opensource">Open Source</span>: .NET command and control framework.
*   **[Mythic](https://github.com/its-a-feature/Mythic)** <span class="badge badge-opensource">Open Source</span>: Cross-platform, post-exploit, red teaming framework.
*   **[Brute Ratel C4](https://bruteratel.com/)** <span class="badge badge-commercial">Commercial</span>: Advanced Red Team & Adversary Simulation Software.
*   **[merlin](https://github.com/Ne0nd0g/merlin)** <span class="badge badge-opensource">Open Source</span>: Cross-platform post-exploitation C2 server and agent written in Go.
*   **[shad0w](https://github.com/bats3c/shad0w)** <span class="badge badge-opensource">Open Source</span>: Post exploitation framework designed to operate covertly.
*   **[Pupy](https://github.com/n1nj4sec/pupy)** <span class="badge badge-opensource">Open Source</span>: Cross-platform remote administration and post-exploitation tool.
*   **[NimPlant](https://github.com/chvancooten/NimPlant)** <span class="badge badge-opensource">Open Source</span>: Light first-stage C2 implant written in Nim and Python.
*   **[SharpC2](https://github.com/rasta-mouse/SharpC2)** <span class="badge badge-opensource">Open Source</span>: C2 framework written in C#.
*   **[Nimhawk](https://github.com/hdbreaker/Nimhawk)** <span class="badge badge-opensource">Open Source</span>: Powerful, modular, lightweight and efficient command & control framework written in Nim.
*   **[AdaptixC2](https://github.com/Adaptix-Framework/AdaptixC2)** <span class="badge badge-opensource">Open Source</span>: Extensible post-exploitation and adversarial emulation framework.
*   **[Loki](https://github.com/boku7/Loki)** <span class="badge badge-opensource">Open Source</span>: Node.js Command & Control for Script-Jacking Vulnerable Electron Applications.
*   **[SILENTTRINITY](https://github.com/byt3bl33d3r/SILENTTRINITY)** <span class="badge badge-opensource">Open Source</span>: Asynchronous, collaborative post-exploitation agent powered by Python and .NET.
