# Reconnaissance Resources

Reconnaissance is the first phase of the Cyber Kill Chain, involving research, identification, and selection of targets.

## Tools

### Scanners & Frameworks
*   **[Argus](https://github.com/jasonxtn/argus)** <span class="badge badge-opensource">Open Source</span>: Python-powered toolkit for information gathering and reconnaissance.
*   **[RustScan](https://github.com/RustScan/RustScan)** <span class="badge badge-opensource">Open Source</span>: The Modern Port Scanner. Find ports quickly (3 seconds at its fastest). Run scripts through our scripting engine (Python, Lua, Shell supported).
*   **[Amass](https://github.com/OWASP/Amass)** <span class="badge badge-opensource">Open Source</span>: In-depth Attack Surface Mapping and Asset Discovery.
*   **[Nmap](https://nmap.org/)** <span class="badge badge-free">Free</span>: The "Network Mapper", free and open source utility for network discovery and security auditing.
*   **[nmapUnleashed](https://github.com/Sharkeonix/nmap-unleashed)** <span class="badge badge-opensource">Open Source</span>: A powerful CLI wrapper enhancing Nmap’s capabilities with multithreading and a dashboard.
*   **[Masscan](https://github.com/robertdavidgraham/masscan)** <span class="badge badge-opensource">Open Source</span>: Internet-scale port scanner, transmitting 10 million packets per second.
*   **[Naabu](https://github.com/projectdiscovery/naabu)** <span class="badge badge-opensource">Open Source</span>: A fast port scanning tool written in Go that enumerates valid ports in a reliable manner.
*   **[OpenVAS](https://www.openvas.org/)** <span class="badge badge-free">Free</span>: Full-featured vulnerability scanner with extensive testing capabilities.
*   **[Nikto](https://cirt.net/Nikto2)** <span class="badge badge-opensource">Open Source</span>: Open Source web server scanner for over 6700 potentially dangerous files/programs.
*   **[Sn1per](https://github.com/1N3/Sn1per)** <span class="badge badge-opensource">Open Source</span>: Automated scanner for enumeration and vulnerability scanning.
*   **[Osmedeus](https://github.com/j3ssie/Osmedeus)** <span class="badge badge-opensource">Open Source</span>: Workflow engine for offensive security, running awesome tools for recon and vulnerability scanning.
*   **[D0rkerR3con Framework](https://github.com/blackhatethicalhacking/D0rkerR3con-Framework)** <span class="badge badge-opensource">Open Source</span>: Offensive Recon toolkit to discover exposed files, secrets, and launch weaponized Google Dorks.
*   **[Recon-ng](https://github.com/lanmaster53/recon-ng)** <span class="badge badge-opensource">Open Source</span>: Open Source Intelligence gathering tool aimed at reducing the time spent harvesting information from open sources.
*   **[Scanners-Box](https://github.com/We5ter/Scanners-Box)** <span class="badge badge-opensource">Open Source</span>: A powerful and open-source toolkit for hackers and security automation.
*   **[Reconness](https://github.com/reconness/reconness)** <span class="badge badge-opensource">Open Source</span>: ReconNess helps you to run and keep all your recon in the same place.
*   **[Lazyrecon](https://github.com/nahamsec/lazyrecon)** <span class="badge badge-opensource">Open Source</span>: Script written in Bash to automate tedious tasks of reconnaissance and information gathering.
*   **[reconFTW](https://github.com/six2dez/reconftw)** <span class="badge badge-opensource">Open Source</span>: A powerful automated reconnaissance tool designed for security researchers.
*   **[axiom](https://github.com/pry0cc/axiom)** <span class="badge badge-opensource">Open Source</span>: A distributed dynamic infrastructure framework for offensive security operations.
*   **[Trivy](https://github.com/aquasecurity/trivy)** <span class="badge badge-opensource">Open Source</span>: Comprehensive and versatile security scanner for vulnerabilities and misconfigurations.

### Domain & DNS
*   **[Subfinder](https://github.com/projectdiscovery/subfinder)** <span class="badge badge-opensource">Open Source</span>: Subdomain discovery tool that discovers valid subdomains for websites by using passive online sources.
*   **[Puredns](https://github.com/d3mondev/puredns)** <span class="badge badge-opensource">Open Source</span>: Fast, professional DNS resolver. Replaces Altdns/Massdns for many workflows.
*   **[Chaos](https://chaos.projectdiscovery.io/)** <span class="badge badge-opensource">Open Source</span>: Actively scans and maintains internet-wide assets' data.
*   **[Dnsprobe](https://github.com/projectdiscovery/dnsprobe)** <span class="badge badge-opensource">Open Source</span>: Tool built on top of retryabledns that allows you to perform multiple DNS queries.
*   **[Shuffledns](https://github.com/projectdiscovery/shuffledns)** <span class="badge badge-opensource">Open Source</span>: Wrapper around massdns that allows you to enumerate valid subdomains using active bruteforce.
*   **[Findomain](https://github.com/Edu4rdSHL/findomain)** <span class="badge badge-opensource">Open Source</span>: Offers dedicated monitoring service for target domains and alerts.
*   **[Dnsgen](https://github.com/ProjectAnte/dnsgen)** <span class="badge badge-opensource">Open Source</span>: Generates a combination of domain names from the provided input.
*   **[Gotator](https://github.com/Josue87/gotator)** <span class="badge badge-opensource">Open Source</span>: Powerful permutation generation for subdomains.
*   **[Massdns](https://github.com/blechschmidt/massdns)** <span class="badge badge-opensource">Open Source</span>: High-performance DNS stub resolver.
*   **[Sublert](https://github.com/yassineaboukir/sublert)** <span class="badge badge-opensource">Open Source</span>: Security and reconnaissance tool to leverage certificate transparency for monitoring new subdomains.
*   **[Subjack](https://github.com/haccer/subjack)** <span class="badge badge-opensource">Open Source</span>: Subdomain Takeover tool written in Go.
*   **[dnscan](https://github.com/rbsec/dnscan)** <span class="badge badge-opensource">Open Source</span>: A python wordlist-based DNS subdomain scanner.

### Web & OSINT
*   **[Wappalyzer](https://addons.mozilla.org/en-US/firefox/addon/wappalyzer/)** <span class="badge badge-free">Free</span>: Browser extension that uncovers the technologies used on websites.
*   **[BuiltWith](https://addons.mozilla.org/en-US/firefox/addon/builtwith/)** <span class="badge badge-free">Free</span>: Helps find out what technologies web pages are using.
*   **[WhatWeb](https://github.com/urbanadventurer/WhatWeb)** <span class="badge badge-opensource">Open Source</span>: Recognizes web technologies including CMS, blogging platforms, statistic/analytics packages, etc.
*   **[Gau](https://github.com/lc/gau)** <span class="badge badge-opensource">Open Source</span>: Fetch known URLs from AlienVault's Open Threat Exchange, the Wayback Machine, and Common Crawl.
*   **[Waybackurls](https://github.com/tomnomnom/waybackurls)** <span class="badge badge-opensource">Open Source</span>: Fetch known URLs from the Wayback Machine.
*   **[Meg](https://github.com/tomnomnom/meg)** <span class="badge badge-opensource">Open Source</span>: Tool for fetching lots of URLs without taking a toll on the servers.
*   **[Katana](https://github.com/projectdiscovery/katana)** <span class="badge badge-opensource">Open Source</span>: A next-generation crawling and spidering framework.
*   **[Feroxbuster](http://github.com/epi052/feroxbuster)** <span class="badge badge-opensource">Open Source</span>: A Rust-based content discovery tool. Faster, smarter, and more modern than Dirb/DirBuster.
*   **[Dirsearch](https://github.com/maurosoria/dirsearch)** <span class="badge badge-opensource">Open Source</span>: A simple command line tool designed to brute force directories and files in websites.
*   **[Ffuf](https://github.com/ffuf/ffuf)** <span class="badge badge-opensource">Open Source</span>: A fast web fuzzer written in Go.
*   **[httpx](https://www.python-httpx.org/)** <span class="badge badge-free">Free</span>: Fast and multi-purpose HTTP toolkit that allows running multiple probes.
*   **[EyeWitness](https://github.com/FortyNorthSecurity/EyeWitness)** <span class="badge badge-opensource">Open Source</span>: Designed to take screenshots of websites, provide some server header info, and identify default credentials.
*   **[Gowitness](https://github.com/sensepost/gowitness)** <span class="badge badge-opensource">Open Source</span>: Website screenshot utility written in Golang using Chrome Headless.
*   **[SpiderFoot](https://github.com/smicallef/spiderfoot)** <span class="badge badge-opensource">Open Source</span>: Open source intelligence (OSINT) automation tool.
*   **[Maltego](https://www.maltego.com/)** <span class="badge badge-commercial">Commercial</span>: OSINT and graphical link analysis tool for gathering and connecting information.
*   **[Shodan](https://www.shodan.io/)** <span class="badge badge-commercial">Commercial</span>: Search engine for Internet-connected devices.
*   **[Censys](https://censys.io/)** <span class="badge badge-commercial">Commercial</span>: Scans the most ports and houses the biggest certificate database in the world.
*   **[Jsluice](https://github.com/BishopFox/jsluice)** <span class="badge badge-opensource">Open Source</span>: Extract URLs, paths, secrets, and other interesting data from JavaScript source code.
*   **[Unfurl](https://github.com/tomnomnom/unfurl)** <span class="badge badge-opensource">Open Source</span>: Parse URLs and pull out content based on criteria.
*   **[Asnlookup](https://www.ultratools.com/tools/asnInfo)** <span class="badge badge-free">Free</span>: Displays information about an IP address's Autonomous System Number (ASN).
*   **[Virtual-host-discovery](https://github.com/jobertabma/virtual-host-discovery)** <span class="badge badge-opensource">Open Source</span>: Enumerates virtual hosts on a given IP address.
*   **[WitnessMe](https://github.com/byt3bl33d3r/WitnessMe)** <span class="badge badge-opensource">Open Source</span>: Web Inventory tool, takes screenshots of webpages using Pyppeteer.
*   **[BBOT](https://github.com/blacklanternsecurity/bbot)** <span class="badge badge-opensource">Open Source</span>: Recursive internet scanner designed to be faster and more reliable.
*   **[ENScan_GO](https://github.com/wgpsec/ENScan_GO)** <span class="badge badge-opensource">Open Source</span>: Tool based on major enterprise information APIs to solve problems in collecting domestic enterprise information (ICP, APP, WeChat, etc.).
*   **[dismap](https://github.com/zhzyker/dismap)** <span class="badge badge-opensource">Open Source</span>: Asset discovery and identification tool for rapid web fingerprint recognition.
