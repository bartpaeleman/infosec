# Weaponization Resources

Weaponization involves coupling a remote access trojan with an exploit into a deliverable payload.

## Tools (Payload Development)

*   **[Ysoserial](https://github.com/frohoff/ysoserial)** <span class="badge badge-opensource">Open Source</span>: A proof-of-concept tool for generating payloads that exploit unsafe Java object deserialization.
*   **[Payloads All The Things](https://github.com/swisskyrepo/PayloadsAllTheThings)** <span class="badge badge-opensource">Open Source</span>: A list of useful payloads and bypasses for Web Application Security.
*   **[GhostStrike](https://github.com/stivenhacker/GhostStrike)** <span class="badge badge-opensource">Open Source</span>: Deploy stealthy reverse shells using advanced process hollowing.
*   **[Ivy](https://github.com/optiv/Ivy)** <span class="badge badge-opensource">Open Source</span>: Payload creation framework for the execution of arbitrary VBA (macro) source code directly in memory.
*   **[PEzor](https://github.com/phra/PEzor)** <span class="badge badge-opensource">Open Source</span>: Open-Source PE Packer.
*   **[GadgetToJScript](https://github.com/med0x2e/GadgetToJScript)** <span class="badge badge-opensource">Open Source</span>: Generates .NET serialized gadgets that can trigger .NET assembly load/execution when deserialized.
*   **[ScareCrow](https://github.com/optiv/ScareCrow)** <span class="badge badge-opensource">Open Source</span>: Payload creation framework designed around EDR bypass.
*   **[Donut](https://github.com/TheWover/donut)** <span class="badge badge-opensource">Open Source</span>: Position-independent code that enables in-memory execution of VBScript, JScript, EXE, DLL files and dotNET assemblies.
*   **[Mystikal](https://github.com/D00MFist/Mystikal)** <span class="badge badge-opensource">Open Source</span>: macOS Initial Access Payload Generator.
*   **[charlotte](https://github.com/9emin1/charlotte)** <span class="badge badge-opensource">Open Source</span>: C++ fully undetected shellcode launcher.
*   **[InvisibilityCloak](https://github.com/xforcered/InvisibilityCloak)** <span class="badge badge-opensource">Open Source</span>: Obfuscation toolkit for C# post-exploitation tools.
*   **[Dendrobate](https://github.com/FuzzySecurity/Dendrobate)** <span class="badge badge-opensource">Open Source</span>: Framework that facilitates the development of payloads that hook unmanaged code through managed .NET code.
*   **[Offensive VBA and XLS Entanglement](https://github.com/BC-SECURITY/Offensive-VBA-and-XLS-Entanglement)** <span class="badge badge-opensource">Open Source</span>: Examples of how VBA can be used for offensive purposes.
*   **[xlsGen](https://github.com/aaaddress1/xlsGen)** <span class="badge badge-opensource">Open Source</span>: Tiny Excel BIFF8 Generator, to Embedded 4.0 Macros in *.xls.
*   **[darkarmour](https://github.com/bats3c/darkarmour)** <span class="badge badge-opensource">Open Source</span>: Windows AV Evasion.
*   **[InlineWhispers](https://github.com/outflanknl/InlineWhispers)** <span class="badge badge-opensource">Open Source</span>: Tool for working with Direct System Calls in Cobalt Strike's Beacon Object Files (BOF).
*   **[EvilClippy](https://github.com/outflanknl/EvilClippy)** <span class="badge badge-opensource">Open Source</span>: Assistant for creating malicious MS Office documents.
*   **[OfficePurge](https://github.com/fireeye/OfficePurge)** <span class="badge badge-opensource">Open Source</span>: VBA purge your Office documents.
*   **[ThreatCheck](https://github.com/rasta-mouse/ThreatCheck)** <span class="badge badge-opensource">Open Source</span>: Identifies the bytes that Microsoft Defender / AMSI Consumer flags on.
*   **[CrossC2](https://github.com/gloxec/CrossC2)** <span class="badge badge-opensource">Open Source</span>: Generate CobaltStrike's cross-platform payload.
*   **[Ruler](https://github.com/sensepost/ruler)** <span class="badge badge-opensource">Open Source</span>: Tool that allows you to interact with Exchange servers remotely.
*   **[DueDLLigence](https://github.com/fireeye/DueDLLigence)** <span class="badge badge-opensource">Open Source</span>: Shellcode runner framework for application whitelisting bypasses and DLL side-loading.
*   **[RuralBishop](https://github.com/rasta-mouse/RuralBishop)** <span class="badge badge-opensource">Open Source</span>: P/Invoke calls replaced with D/Invoke.
*   **[TikiTorch](https://github.com/rasta-mouse/TikiTorch)** <span class="badge badge-opensource">Open Source</span>: Spawns a new process, allocates memory, then uses CreateRemoteThread to run shellcode.
*   **[SharpShooter](https://github.com/mdsecactivebreach/SharpShooter)** <span class="badge badge-opensource">Open Source</span>: Payload creation framework for the retrieval and execution of arbitrary CSharp source code.
*   **[SharpSploit](https://github.com/cobbr/SharpSploit)** <span class="badge badge-opensource">Open Source</span>: .NET post-exploitation library written in C#.
*   **[MSBuildAPICaller](https://github.com/rvrsh3ll/MSBuildAPICaller)** <span class="badge badge-opensource">Open Source</span>: MSBuild Without MSBuild.exe.
*   **[macro_pack](https://github.com/sevagas/macro_pack)** <span class="badge badge-opensource">Open Source</span>: Tool used to automatize obfuscation and generation of MS Office documents, VB scripts, etc.
*   **[inceptor](https://github.com/klezVirus/inceptor)** <span class="badge badge-opensource">Open Source</span>: Template-Driven AV/EDR Evasion Framework.
*   **[mortar](https://github.com/0xsp-SRD/mortar)** <span class="badge badge-opensource">Open Source</span>: Evasion technique to defeat and divert detection and prevention of security products.
*   **[ProtectMyTooling](https://github.com/mgeeky/ProtectMyTooling)** <span class="badge badge-opensource">Open Source</span>: Multi-Packer wrapper letting us daisy-chain various packers, obfuscators.
*   **[Freeze](https://github.com/optiv/Freeze)** <span class="badge badge-opensource">Open Source</span>: Payload toolkit for bypassing EDRs using suspended processes, direct syscalls.
*   **[Shhhloader](https://github.com/icyguider/Shhhloader)** <span class="badge badge-opensource">Open Source</span>: Shellcode loader that compiles a C++ stub to bypass AV/EDR.
*   **[DllShimmer](https://github.com/Print3M/DllShimmer)** <span class="badge badge-opensource">Open Source</span>: Weaponize DLL hijacking easily.
*   **[moonwalk](https://github.com/mufeedvh/moonwalk)** <span class="badge badge-opensource">Open Source</span>: Cover your tracks during Linux Exploitation by leaving zero traces on system logs and filesystem timestamps.
