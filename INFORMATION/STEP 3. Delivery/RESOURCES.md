# Delivery Resources

Delivery is the transmission of the weapon to the targeted environment.

## Phishing Tools

*   **[Gophish](https://github.com/gophish/gophish)** <span class="badge badge-opensource">Open Source</span>: Open-source phishing toolkit designed for businesses and penetration testers.
*   **[Evilginx2](https://github.com/kgretzky/evilginx2)** <span class="badge badge-opensource">Open Source</span>: Man-in-the-middle attack framework used for phishing credentials and session cookies.
*   **[Modlishka](https://github.com/drk1wi/Modlishka)** <span class="badge badge-opensource">Open Source</span>: Flexible and powerful reverse proxy for ethical phishing campaigns.
*   **[o365-attack-toolkit](https://github.com/mdsecactivebreach/o365-attack-toolkit)** <span class="badge badge-opensource">Open Source</span>: A toolkit to attack Office365.
*   **[PwnAuth](https://github.com/fireeye/PwnAuth)** <span class="badge badge-opensource">Open Source</span>: Web application framework for launching and managing OAuth abuse campaigns.
*   **[goblin](https://github.com/xiecat/goblin)** <span class="badge badge-opensource">Open Source</span>: A simulation phishing system suitable for red-blue confrontation.
*   **[Social-Engineer Toolkit (SET)](https://github.com/trustedsec/social-engineer-toolkit)** <span class="badge badge-opensource">Open Source</span>: Open-source penetration testing framework designed for social engineering.
*   **[King Phisher](https://github.com/rsmusllp/king-phisher)** <span class="badge badge-opensource">Open Source</span>: Phishing campaign toolkit.
*   **[ReelPhish](https://github.com/mandiant/ReelPhish)** <span class="badge badge-opensource">Open Source</span>: Automated tool for two-factor authentication phishing.
*   **[Ghost Phisher](https://github.com/savio-code/ghost-phisher)** <span class="badge badge-opensource">Open Source</span>: Wireless and ethernet phishing tool.
*   **[Credential Harvester Attack](https://github.com/trustedsec/social-engineer-toolkit)** <span class="badge badge-opensource">Open Source</span>: Tool in SET for credential theft.

## Other Delivery & Interaction Tools

*   **[Interactsh](https://app.interactsh.com/)** <span class="badge badge-opensource">Open Source</span>: ProjectDiscovery's OOB interaction server. Critical for blind SSRF/XXE/RCE testing.
*   **[BeEF](https://github.com/beefproject/beef)** <span class="badge badge-opensource">Open Source</span>: The Browser Exploitation Framework. Focuses on the web browser.
